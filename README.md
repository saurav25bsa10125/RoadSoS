🎯 Problem Statement
1.5 Lakh deaths/year in India. 50% victims die in Golden Hour due to late medical help.

 💡 Our Solution
On-device TinyML AI detects crash via phone sensors + mic → Auto SOS to 112 in 10 sec with location + blood group + dashcam proof. 100% offline, ₹0 server cost.

 🛠️ Tech Stack - Zero Cost Architecture
- Frontend:** HTML5, JS, CSS - No frameworks, 98KB bundle
- AI/ML:** TensorFlow.js + TinyML - Runs on-device
- Maps:** Leaflet + OpenStreetMap - Free, works offline
- PWA:** Service Workers - Installable, works without internet
- Hosting:** GitHub Pages - ₹0 even for 10 Lakh users

📱 Key Features
1. AI Crash Detection:** Triggers on impact + loud noise
2. 10-Sec Auto-SOS:** Shares medical profile to 112 + Family
3. Offline Dashcam:** Auto-saves video proof for insurance
4. First-Aid Voice Guide:** Speaks steps to save victim
5. Hazard Reporting:** Crowdsourced pothole/accident alerts
